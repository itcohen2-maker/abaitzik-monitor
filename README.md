# מוניטור אבא איציק

מערכת מקומית שמחליפה את ManyChat. נבנתה ב־7.9.2026 אחרי ביטול המנוי.

## הפעלה

```
cd C:\Users\User\abaitzik-monitor
node server.js
```

ואז לפתוח בדפדפן: http://127.0.0.1:4173

בלי התקנות ובלי תלויות. Node בלבד.

## הכלל האדום

**לא פונים למי שלא פנה.** המערכת בנויה כך שאי אפשר בכלל ליצור רשומה
למי שלא יצר קשר ראשון. כל פריט מגיע מתגובה, מתשובה לסטורי או מהודעה
שנשלחה אלינו. פנייה יזומה לעוקבים היא הסימן החזק ביותר לספאם אצל
אינסטגרם ופייסבוק, והחשבון הוא המנוע של כל המשפך.

## מבנה

| קובץ | תפקיד |
|---|---|
| `server.js` | שרת מקומי, מגיש את המוניטור ו־API קטן |
| `public/index.html` | המסך עצמו. סטטיסטיקות, תור, ותיבת פקודות |
| `lib/store.js` | קריאה וכתיבה של `data/state.json` |
| `lib/replies.js` | בנק הניסוחים והוולידציה שמונעת שגיאות |
| `lib/pacing.js` | שעות שקט, מכסות יומיות, והשהיות רנדומליות |
| `seed.js` | טוען את העבודה שכבר נעשתה ידנית |

## בנק התשובות

`lib/replies.js` מחזיק ניסוחים לפי קטגוריה: ברכה, עידוד, אישי, כאב,
המלצה רפואית, הצעת עזרה, ושאלת תרומות. הבחירה נמנעת מלחזור על ניסוח
שהיה בשימוש בארבע התשובות האחרונות, כדי שהפיד לא יראה משפט זהה פעמיים.

הוולידציה חוסמת אוטומטית: מקפים, הבטחות, ופרטי תשלום. כל ניסוח בבנק
עובר את הבדיקה.

## מה עוד לא קיים

איסוף התגובות עדיין נעשה דרך הדפדפן ולא אוטומטית, כי אין API שנותן
"תגובות שלא נענו" בפייסבוק ובאינסטגרם. השלב הבא הוא לחבר את האיסוף
לאותו מסד נתונים כדי שהתור יתמלא לבד.
