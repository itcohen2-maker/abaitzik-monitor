חיבור המחשב למוניטור

1. לחיצה כפולה על install-pc.cmd. לא צריך הרשאות מנהל.
2. ההתקנה מחפשת את Claude Code במחשב, בודקת את החיבור לשרת, ורושמת בדיקה כל דקה ברקע.
3. מרגע זה, משימה שהמוניטור מסמן למחשב הזה רצה כאן לבד עם Claude Code, על החשבון שמחובר כאן, והתשובה חוזרת לצ׳אט במוניטור.

הקבצים מותקנים בתיקייה MonitorPc בתוך AppData\Local של המשתמש.
היומן: MonitorPc\pc-pull.log
תוצרים שהמחשב מפיק נשמרים בתיקייה MonitorWork בפרופיל המשתמש, או ליד קובץ המקור.

להסרה: schtasks /Delete /TN MonitorPcPull /F, ומחיקת התיקייה MonitorPc.
