# לוח לידים בסגנון Monday: תוכנית עבודה

> **לסוכנים שמבצעים:** סקיל חובה: superpowers:subagent-driven-development או superpowers:executing-plans. כל צעד מסומן `- [ ]`.

**המטרה:** להחליף את טבלת הלידים במוניטור של איציק בלוח בסגנון Monday: קבוצות לפי שלב, עריכה ישר בשורה, תזכורת לליד בוואטסאפ, אתר, הערות.

**הארכיטקטורה:** צד השרת: שלוש פעולות חדשות ב lib/leads.js, שעוברות בערוץ ההודעות הקיים "ליד [<id>]: ...". התזכורת נשמרת ב lib/alarms.js עם קישור לליד. צד הדף: פונקציה חדשה `ldBoardHtml()` ב build.js מחליפה את `itsLeadsHtml()`, רק בתוך בלוק `/*ITZIK:BEGIN*/`, ולכן אצל לקוחות נשארת הטבלה הישנה.

**טכנולוגיות:** Node (node:test), JS בתוך template literal ב build.js, CSS באותו קובץ.

**המסמך:** `docs/superpowers/specs/2026-11-18-leads-board-design.md`

## אילוצים כלליים

- **רק אצל איציק בשלב הזה:** איציק אישר ב 18.11 "רק כרגע אצלי במוניטור שלי". הדגל `LD_BOARD` נדלק רק בתוך `/*ITZIK:BEGIN*/…/*ITZIK:END*/`. "מה חסר לך כאן?" (מטרה 10 במסמך) נדחה לשלב הלקוחות.
- **קוד הדף ב build.js:** יושב בתוך template literal. בלי `\D`, `\s` וכדומה ברגקס: כותבים `[^0-9]`, ומעבר שורה כ `String.fromCharCode(10)`.
- **שדה חדש:** כל שדה חדש בליד נכנס ל `BIZ_FIELDS` (build.js שורה 1066 בערך).
- **שעון ישראל תמיד:** `Asia/Jerusalem` בדף, ו `alarms.parseLocal` בשרת.
- **טקסטים:** עברית בלבד, RTL, Heebo, בלי מקפים בטקסט שרואים.
- **שלבים:** `STAGES = ['חדש','בשיחה','הצעה','נסגר','אבד']`. סטטוס לא מוכר מוצג בקבוצה חדש.

## על מה לשים לב בבדיקה

1. **ליד ישן עם `nextAt` של תאריך בלבד** ("2026-11-19"): נחשב 9:00, ומופיע ב"⏰ היום" רק כשהתאריך הגיע.
2. **אתר זדוני:** `javascript:alert(1)` או `"><img onerror>`. השרת דוחה, והדף מציג מוגן.
3. **תזכורת לליד שנמחק או שנסגר:** לא נשלחת.
4. **לוח עם אפס לידים או 300 לידים:** נפתח בלי שגיאה.
5. **העתק של לקוח:** לא מכיל `ldBoardHtml`, ונשארת בו הטבלה הישנה.

### משימה 1: פעולות חדשות בשרת: צעד, אתר, תזכורת

**קבצים:**
- לשנות: `lib/leads.js` (parse, apply, exports)

- בדיקות: `tests/leads.test.js`

**ממשקים:**
- נוצר:
  - `leads.parse(text)` מזהה גם `צעד|אתר|תזכורת`.
  - `leads.apply(dataPath, text, now)` מחזיר `{ok, reply}`.
  - `leads.normSite(s) -> string|''`
  - `alarms.add(dataPath, local, text, now, extra)`, כש `extra = {lead:id}` נשמר ברשומה.
  - `alarms.cancelLead(dataPath, leadId, now) -> number` (כמה בוטלו).

- [ ] **צעד 1: לכתוב בדיקות שנכשלות** ב tests/leads.test.js:
  - `צעד`: `apply(d,'ליד [id]: צעד להתקשר ולהציע דמו')` → `r.next==='להתקשר ולהציע דמו'`, ו `ok` אמת.
  - `אתר`:
    - `normSite('eran.co.il')==='https://eran.co.il'`
    - `normSite('http://a.com/x')==='http://a.com/x'`
    - `normSite('javascript:alert(1)')===''`
    - `normSite('"><img src=x onerror=1>')===''`

    - `apply(... 'אתר ביטול')` → `r.site===''`.
  - `תזכורת`: בשעון קבוע `now=Date.parse('2026-11-18T10:00:00Z')`:
    - `apply(... 'תזכורת 2026-11-19 09:00', now)` → `r.nextAt==='2026-11-19T07:00:00.000Z'`.

    - `'תזכורת ביטול'` → אין תזכורת פתוחה, `r.nextAt===''`.
  - **ביטול אוטומטי:**
    - `סטטוס נסגר` מבטל את התזכורת, וגם `סטטוס אבד`.
    - `מחיקה` מבטלת את התזכורת.
    - `הערה` לא מבטלת.
  - **בזמן שליחה:** `alarms.tick` לא שולח תזכורת עם `lead` שהקובץ שלו ב `data/biz/_deleted`.
